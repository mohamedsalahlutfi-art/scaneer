SmartScan Pro — طريقة استخراج APK مجانًا عن طريق GitHub

1. افتح https://github.com/new وأنشئ حسابًا مجانيًا إذا لم يكن لديك حساب.
2. سمِّ المستودع SmartScan-Pro، ويمكن اختياره Private (لكن قد تُطبق حدود الدقائق المجانية).
3. اضغط Create repository. اختر مستودعًا فارغًا بدون إنشاء README.
4. فُك ضغط SmartScan_Pro_GitHub_Ready.zip على الكمبيوتر.
5. ادخل المجلد SmartScan_Pro_GitHub_Upload وحدد الملفات والمجلدات التي بداخله كلها (ليس المجلد الأب).
6. في GitHub اختر uploading an existing file أو Add file > Upload files، واسحب محتويات المجلد إلى الصفحة.
7. تأكد أن مسار .github/workflows/smartscan-apk.yml في جذر المستودع وأن app/build.gradle.kts في app/ مباشرة.
8. اضغط Commit changes.
9. من تبويب Actions اختر SmartScan Pro - Build Android APK ثم Run workflow.
   يبدأ البناء تلقائيًا بعد الرفع أيضًا على الفرع main.
10. بعد اكتمال العملية بعلامة خضراء، افتح التشغيل ثم Artifacts ثم SmartScan-Pro-APK.
11. نزّل الملف المضغوط الخاص بنتائج البناء، وفك الضغط لتجد SmartScan-Pro.apk.
12. انقل الـ APK إلى هاتف أندرويد وثبّته عبر مدير الملفات، بعد السماح بالتثبيت من هذا المصدر عند الحاجة.

مهم:
- هذه الطريقة تنتج APK فقط إذا نجح الكود في التجميع. الكود لم يُختبر كتطبيق أندرويد كامل حتى الآن.
- لا ترفع أي بيانات شخصية أو مستندات تريد مسحها؛ هذا مستودع كود فقط.
- إذا فشل البناء (علامة حمراء)، افتح خطوة الفشل واحتفظ بسجل الخطأ لإصلاح المشكلة.
- github.com لا يحوّل ZIP مباشرة إلى APK؛ يجب رفع ملفات المشروع بعد فك الضغط.
